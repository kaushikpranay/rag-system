--- WHY BUILT ---
Purpose: Production-ready, self-improving AI customer care system for interviews/resume.
Problem: LLMs hallucinate and fail on domain-specific questions they weren't trained on.
Solution: RAG (retrieve real docs first) + 3-attempt retry loop + human escalation + knowledge accumulation.
Key differentiator: Human-verified answers are embedded and stored in vector DB — reused for ALL future
users automatically. System gets smarter over time without retraining.

--- WHAT IT DOES (7-step flow) ---
1. User asks question via chat UI (chat.html served at /)
2. Agent retrieves relevant docs from pgvector on RDS
3. LLM (Llama 3.1 via Groq) answers using retrieved context + last 4 turns of chat history
4. Evaluation node checks answer against 16 low-confidence phrases
5. If LLM uncertain → retry up to 3x with progressively wider search (top_k↑, min_sim↓)
6. After 3 failures → escalate to human via SQS → Streamlit dashboard
7. Human answers → stored in RDS vector DB → next similar user gets answer instantly

--- TECH STACK ---
LLM inference : Groq API, model=llama-3.1-8b-instant, max_tokens=512
Embeddings    : AWS Bedrock, model=amazon.titan-embed-text-v2:0, dims=1024
State machine : LangGraph StateGraph
Vector DB     : AWS RDS PostgreSQL + pgvector extension
Session memory: AWS DynamoDB, TTL=24h
Message queue : AWS SQS (standard queue)
File storage  : AWS S3 (raw-documents/ for PDFs, verified-answers/ for JSON archives)
Backend API   : FastAPI + uvicorn
Chat UI       : Vanilla HTML/JS (served by FastAPI)
Agent dashboard: Streamlit on port 8501
Process mgr   : supervisor (services: fastapi, streamlit)
Reverse proxy : nginx on port 80 → uvicorn on 8000
CI/CD         : GitHub Actions → pytest → SSH → EC2
Security      : slowapi, PII masking, prompt injection guard, CSP headers, UUID validation

--- DB TABLE SCHEMA ---
Table: documents
  id        SERIAL PRIMARY KEY
  content   TEXT              -- chunk text or "Q: {query}\nA: {answer}" for human_verified
  metadata  JSONB             -- {source, query, session_id, verified_at} or {page, source}
  embedding vector(1024)      -- Bedrock Titan V2 embedding

source field values:
  "human_verified" = answer from Streamlit dashboard agent
  anything else    = ingested from PDF documents

--- INTERVIEW Q&A ---
Q: Why LangGraph not LangChain agent?
A: Deterministic state machine. Enforces retry count and escalation reliably. Agents are non-deterministic.

Q: Why Groq not OpenAI?
A: Sub-200ms inference, LLaMA 3.1 is open source, free tier generous for demos.

Q: Why pgvector not Pinecone?
A: Single AWS service (RDS) handles relational + vector. Reduces infra complexity and cost.

Q: How does cross-user knowledge sharing work?
A: Human answer → embed QUERY only → store with source:human_verified → retrieval_node checks
   this pool FIRST using semantic search → paraphrased questions still match via cosine similarity.

Q: What if human doesn't answer?
A: Polling times out after 5 minutes (60 polls × 5 seconds). User sees timeout message.

Q: How is chat memory maintained across turns?
A: DynamoDB stores [{query,answer,timestamp}] per session_id. Last 4 turns injected into prompt.

Q: What security measures are in place?
A: Rate limiting (slowapi), prompt injection detection (regex patterns), PII masking in all logs
   (email/phone/card/SSN), UUID session_id validation, CSP/HSTS/XSS headers, error masking
   (raw exceptions logged server-side only), XSS sanitization with html.escape in dashboard.

### FILE: app/agent/graph.py ###
import os, uuid, logging
from groq import Groq
from dotenv import load_dotenv
from langgraph.graph import StateGraph, END
from typing import TypedDict, List, Optional
from app.retrieval.pgvector_client import retrieve_similar
from app.memory.dynamodb_client import get_session, save_session
from app.escalation.sqs_worker import send_to_sqs
from app.utils.sanitizer import mask_pii
load_dotenv()
logger = logging.getLogger(__name__)

class AgentState(TypedDict):
    query: str; session_id: str; chat_history: List[dict]
    retrieved_chunks: List[dict]; context: str; answer: str
    confidence: str; escalate: bool; retry_count: int; error: Optional[str]

def input_node(state):
    query = state["query"].strip()
    if not query: return {**state, "error": "Empty query received"}
    logger.info(f"[input_node] Query: {mask_pii(query[:80])}")
    return {**state, "query": query, "error": None}

def session_node(state):
    session_id = state.get("session_id", "default-session")
    history = get_session(session_id)
    logger.info(f"[session_node] Session: {session_id}, History: {len(history)}")
    return {**state, "chat_history": history}

def retrieval_node(state):
    query = state["query"]
    retry_count = state.get("retry_count", 0)
    logger.info(f"[retrieval_node] Attempt {retry_count+1}/3")
    human_threshold = max(0.40, 0.55-(retry_count*0.05))  # 0.55→0.50→0.45
    top_k = 5 + (retry_count*3)                            # 5→8→11
    min_sim = max(0.10, 0.30-(retry_count*0.10))           # 0.30→0.20→0.10
    try:
        from app.retrieval.pgvector_client import search_human_verified
        human_results = search_human_verified(query, top_k=3)
        if human_results and human_results[0][2] > human_threshold:
            logger.info(f"[retrieval_node] Human-verified found. Sim={human_results[0][2]:.2f}")
            return {**state,
                "retrieved_chunks": [{"content":human_results[0][0],"metadata":human_results[0][1],"similarity":human_results[0][2]}],
                "context": human_results[0][0]}
        chunks = retrieve_similar(query, top_k=top_k, min_similarity=min_sim)
        logger.info(f"[retrieval_node] {len(chunks)} chunks (top_k={top_k}, min_sim={min_sim})")
        return {**state, "retrieved_chunks": chunks}
    except Exception as e:
        logger.error(f"[retrieval_node] Failed: {e}")
        return {**state, "retrieved_chunks": []}

def context_node(state):
    if state.get("context") and state["context"].strip():
        logger.info("[context_node] Using pre-set human-verified context")
        return state
    chunks = state["retrieved_chunks"]
    if not chunks: context = "No relevant context found"
    else: context = "\n\n".join([f"[Chunk {i+1} | Similarity: {c['similarity']:.2f}]\n{c['content']}" for i,c in enumerate(chunks)])
    logger.info(f"[context_node] Built from {len(chunks)} chunks")
    return {**state, "context": context}

def llm_node(state):
    query = state["query"]; context = state["context"]
    history_str = ""
    for msg in state["chat_history"][-4:]:
        if msg.get("query"): history_str += f"User: {msg['query']}\n"
        if msg.get("answer"): history_str += f"Assistant: {msg['answer']}\n"
    prompt = f"""You are a helpful customer care assistant. Use the following information to answer the user's question:
1. **Chat History** - for conversational context (follow-ups, references to previous messages)
2. **Retrieved Context** - for factual/domain-specific answers
Rules:
- Answer from chat history if user asks about previous conversation.
- Answer from retrieved context for factual questions.
- If NEITHER has enough info, say exactly: "I don't have enough information to answer this."
- Do NOT make up information. Only use what is provided.
- Answer naturally. Do NOT say "based on our previous conversation" or "according to chat history".
- Only reference past conversations if user explicitly asks (e.g. "what did I ask before?").
Chat History:\n{history_str}
Retrieved Context:\n{context}
User Question: {query}
Answer:"""
    try:
        client = Groq(api_key=os.getenv("GROQ_API_KEY"))
        response = client.chat.completions.create(
            model="llama-3.1-8b-instant",
            messages=[{"role":"user","content":prompt}],
            max_tokens=512)
        answer = response.choices[0].message.content.strip()
        logger.info(f"[llm_node] Answer generated ({len(answer)} chars)")
        return {**state, "answer": answer}
    except Exception as e:
        logger.error(f"[llm_node] LLM call failed: {e}")
        return {**state, "answer": "I'm sorry, I'm experiencing technical difficulties. Please try again shortly."}

def evaluation_node(state):
    answer = state["answer"]; retry_count = state.get("retry_count",0)
    low_confidence_phrases = [
        "i don't have enough information","i don't have the information",
        "i can not answer","i cannot answer","i'm not able to answer",
        "i am not able to answer","not enough information","no relevant information",
        "no information available","cannot provide an answer","don't have enough context",
        "does not contain enough information","i'm sorry, i don't know","i'm unable to",
        "the context does not","not mentioned in the context","no relevant context"]
    llm_refused = any(p in answer.lower() for p in low_confidence_phrases)
    if not llm_refused:
        logger.info(f"[evaluation_node] Confidence: high | Attempt: {retry_count+1}")
        return {**state, "confidence":"high", "escalate":False}
    if retry_count < 2:
        new_retry = retry_count+1
        logger.info(f"[evaluation_node] LLM refused — retrying ({new_retry}/3)")
        return {**state,"confidence":"retry","escalate":False,"retry_count":new_retry,"context":"","retrieved_chunks":[]}
    logger.info("[evaluation_node] All 3 attempts failed — escalating")
    return {**state, "confidence":"low", "escalate":True}

def output_node(state):
    session_id = state.get("session_id","default-session")
    if state["escalate"]:
        send_to_sqs(session_id, state["query"], state["answer"])
        escalation_msg = ("I don't have the answer for this. I've asked my team — they're on it. "
                          "Ask me the same question again in about 1 minute. I'll have the answer.")
        save_session(session_id, state["query"], escalation_msg)
        logger.info("[output_node] Escalating to SQS")
        return {**state, "answer": escalation_msg}
    save_session(session_id, state["query"], state["answer"])
    logger.info("[output_node] Resolved — saved to DynamoDB")
    return state

def route_after_input(state):
    return END if state.get("error") else "session_node"

def route_after_evaluation(state):
    return "retrieval_node" if state.get("confidence")=="retry" else "output_node"

def build_agent():
    graph = StateGraph(AgentState)
    for name, fn in [("input_node",input_node),("session_node",session_node),
                     ("retrieval_node",retrieval_node),("context_node",context_node),
                     ("llm_node",llm_node),("evaluation_node",evaluation_node),("output_node",output_node)]:
        graph.add_node(name, fn)
    graph.set_entry_point("input_node")
    graph.add_conditional_edges("input_node", route_after_input)
    graph.add_edge("session_node","retrieval_node"); graph.add_edge("retrieval_node","context_node")
    graph.add_edge("context_node","llm_node"); graph.add_edge("llm_node","evaluation_node")
    graph.add_conditional_edges("evaluation_node", route_after_evaluation)
    graph.add_edge("output_node", END)
    return graph.compile()

agent = build_agent()

def run_agent(query: str, session_id: str = "test-session") -> dict:
    if session_id is None: session_id = str(uuid.uuid4())
    initial_state = AgentState(query=query, session_id=session_id, chat_history=[],
        retrieved_chunks=[], context="", answer="", confidence="", escalate=False, retry_count=0, error=None)
    result = agent.invoke(initial_state)
    return {"answer":result["answer"],"confidence":result["confidence"],"escalate":result["escalate"],"session_id":result["session_id"]}

class SecurityHeadersMiddleware(BaseHTTPMiddleware):
    async def dispatch(self, request, call_next):
        response = await call_next(request)
        response.headers["X-Content-Type-Options"] = "nosniff"
        response.headers["X-Frame-Options"] = "DENY"
        response.headers["X-XSS-Protection"] = "1; mode=block"
        response.headers["Strict-Transport-Security"] = "max-age=31536000; includeSubDomains"
        response.headers["Content-Security-Policy"] = "default-src 'self'; script-src 'self' 'unsafe-inline'; style-src 'self' 'unsafe-inline'"
        response.headers["Referrer-Policy"] = "no-referrer"
        return response

class QueryRequest(BaseModel):
    query: str; session_id: Optional[str] = None
    @field_validator("query")
    @classmethod
    def validate_query(cls, v):
        cleaned = sanitize_query(v)
        if not cleaned: raise ValueError("Query cannot be empty")
        if len(cleaned) > 1000: raise ValueError("Query exceeds 1000 characters")
        return cleaned

class QueryResponse(BaseModel):
    session_id: str; query: str; answer: str; confidence: str; escalated: bool

@app.get("/health")
def health(): return {"status": "ok"}

@app.post("/query", response_model=QueryResponse)
@limiter.limit("20/minute")
def resolve_query(request: Request, body: QueryRequest):
    try:
        session_id = body.session_id or str(uuid.uuid4())
        logger.info(f"[query] session={session_id} query={mask_pii(body.query[:80])}")
        if detect_prompt_injection(body.query):
            logger.warning(f"[query] Prompt injection blocked session={session_id}")
            return QueryResponse(session_id=session_id, query=body.query,
                answer="I can only help with customer support questions. Please rephrase.",
                confidence="blocked", escalated=False)
        result = run_agent(body.query, session_id)
        return QueryResponse(session_id=session_id, query=body.query,
            answer=result["answer"], confidence=result["confidence"], escalated=result["escalate"])
    except Exception as e:
        logger.error(f"Query resolution failed: {e}")
        raise HTTPException(status_code=500, detail="An internal error occurred. Please try again.")

@app.get("/queue-status/{session_id}")
@limiter.limit("30/minute")
def queue_status(request: Request, session_id: str, query: str = ""):
    try: uuid.UUID(session_id)
    except ValueError: raise HTTPException(status_code=400, detail="Invalid session ID format")
    conn = get_connection()
    try:
        cur = conn.cursor(); row = None
        if query.strip():
            cur.execute("SELECT content FROM documents WHERE metadata->>'source'='human_verified' AND metadata->>'session_id'=%s AND LOWER(metadata->>'query')=LOWER(%s) ORDER BY id DESC LIMIT 1",(session_id,query.strip()))
            row = cur.fetchone()
            if not row:
                cur.execute("SELECT content FROM documents WHERE metadata->>'source'='human_verified' AND LOWER(metadata->>'query')=LOWER(%s) ORDER BY id DESC LIMIT 1",(query.strip(),))
                row = cur.fetchone()
        else:
            cur.execute("SELECT content FROM documents WHERE metadata->>'session_id'=%s AND metadata->>'source'='human_verified' ORDER BY id DESC LIMIT 1",(session_id,))
            row = cur.fetchone()
        cur.close()
    finally: conn.close()
    if row: return {"in_queue": False, "answer": row[0]}
    return {"in_queue": True, "answer": None}

import os, logging, psycopg2, boto3, json
from dotenv import load_dotenv
from pgvector.psycopg2 import register_vector
load_dotenv()
logger = logging.getLogger(__name__)
RDS_HOST=os.getenv("RDS_HOST"); RDS_PORT=os.getenv("RDS_PORT",5432)
RDS_DB=os.getenv("RDS_DB","ragdb"); RDS_USER=os.getenv("RDS_USER","ragadmin")
RDS_PASSWORD=os.getenv("RDS_PASSWORD"); AWS_REGION=os.getenv("AWS_REGION","us-east-1")
_bedrock_client = boto3.client("bedrock-runtime", region_name=AWS_REGION)  # module-level, reused

def get_connection():
    conn = psycopg2.connect(host=RDS_HOST,port=RDS_PORT,dbname=RDS_DB,user=RDS_USER,password=RDS_PASSWORD)
    register_vector(conn); return conn

def get_bedrock_embedding(text: str) -> list:
    body = json.dumps({"inputText": text})
    response = _bedrock_client.invoke_model(modelId="amazon.titan-embed-text-v2:0",
        contentType="application/json",accept="application/json",body=body)
    return json.loads(response["body"].read())["embedding"]

def store_chunks(chunks: list):
    conn = get_connection(); cur = conn.cursor(); stored = 0
    for chunk in chunks:
        clean_text = chunk.page_content.replace('\x00','').strip()
        if not clean_text: continue
        embedding = get_bedrock_embedding(clean_text)
        cur.execute("INSERT INTO documents (content,metadata,embedding) VALUES (%s,%s,%s)",
            (clean_text, json.dumps(chunk.metadata), embedding))
        stored += 1
    conn.commit(); cur.close(); conn.close()
    logger.info(f"[pgvector] {stored} chunks stored")

def retrieve_similar(query: str, top_k: int=5, min_similarity: float=0.3) -> list:
    embedding = get_bedrock_embedding(query)
    emb_str = "["+",".join(map(str,embedding))+"]"
    conn = get_connection(); cur = conn.cursor()
    cur.execute("""SELECT content,metadata,1-(embedding<=>%s::vector) AS similarity
        FROM documents WHERE 1-(embedding<=>%s::vector)>%s
        ORDER BY embedding<=>%s::vector LIMIT %s""",
        (emb_str,emb_str,min_similarity,emb_str,top_k))
    results = cur.fetchall(); cur.close(); conn.close()
    return [{"content":r[0],"metadata":r[1],"similarity":r[2]} for r in results]

def search_human_verified(query: str, top_k: int=3):
    # Only searches rows where metadata->>'source' = 'human_verified'
    # Embedding is on QUERY only (not the answer) for correct matching
    conn = get_connection(); cur = conn.cursor()
    embedding = get_bedrock_embedding(query)

import boto3, os
from datetime import datetime, timezone, timedelta
from dotenv import load_dotenv
load_dotenv()
DYNAMODB_TABLE = os.getenv("DYNAMODB_TABLE","rag-session-memory")
AWS_REGION = os.getenv("AWS_REGION","us-east-1")
dynamodb = boto3.resource("dynamodb", region_name=AWS_REGION)
table = dynamodb.Table(DYNAMODB_TABLE)

def get_session(session_id: str) -> list:
    try:
        response = table.get_item(Key={"session_id": session_id})
        item = response.get("Item")
        if not item: return []
        return item.get("history", [])
    except Exception as e:
        print(f"[dynamodb] get_session error: {e}"); return []

def save_session(session_id: str, query: str, answer: str) -> None:
    try:
        history = get_session(session_id)
        history.append({"query":query,"answer":answer,"timestamp":datetime.now(timezone.utc).isoformat()})
        ttl = int((datetime.now(timezone.utc)+timedelta(hours=24)).timestamp())
        table.put_item(Item={"session_id":session_id,"history":history,"expires_at":ttl})
    except Exception as e:
        print(f"[dynamodb] save_session error: {e}")

def send_to_sqs(session_id, query, answer) -> bool:
    try:
        sqs.send_message(QueueUrl=SQS_QUEUE_URL,
            MessageBody=json.dumps({"session_id":session_id,"query":query,"answer":answer}))
        print(f"[sqs] Sent: {query}"); return True
    except Exception as e: print(f"[sqs] send error: {e}"); return False

def receive_from_sqs(max_messages=10) -> list:
    try:
        response = sqs.receive_message(QueueUrl=SQS_QUEUE_URL,
            MaxNumberOfMessages=max_messages,WaitTimeSeconds=5)
        return response.get("Messages",[])
    except Exception as e: print(f"[sqs] receive error: {e}"); return []

def delete_from_sqs(receipt_handle) -> None:
    try: sqs.delete_message(QueueUrl=SQS_QUEUE_URL,ReceiptHandle=receipt_handle)
    except Exception as e: print(f"[sqs] delete error: {e}")

    (re.compile(r'(\+?\d{1,3}[-.\ s]?)?\(?\d{3}\)?[-.\ s]?\d{3}[-.\ s]?\d{4}'), '[PHONE_REDACTED]'),
    (re.compile(r'\b\d{4}[-\ s]?\d{4}[-\ s]?\d{4}[-\ s]?\d{1,7}\b'), '[CARD_REDACTED]'),
    (re.compile(r'\b\d{3}-\d{2}-\d{4}\b'), '[SSN_REDACTED]'),
]
def mask_pii(text):
    for pattern, replacement in _PII_PATTERNS: text = pattern.sub(replacement, text)
    return text
def sanitize_query(query):
    if not query: return ""
    cleaned = re.sub(r'[\x00-\x08\x0b\x0c\x0e-\x1f\x7f]','',query).strip()
    return cleaned[:1000]
